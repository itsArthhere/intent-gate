INTENTGATE / LOCAL SYSTEM

Route when confident. Defer otherwise.

A supervised intent classifier with an explicit rejection policy. Training, policy selection and held-out evaluation are separate stages; the application loads one frozen artifact.

Separate decisions

Classification chooses a candidate intent. The acceptance policy decides whether to expose it. Neither decision grants permission to execute an action.

Measure the misses

Supported accuracy alone hides unsupported requests routed by mistake. Evaluation reports false acceptance and accepted-request accuracy separately.

Keep deployment honest

This is a local application. Authentication, queues and monitoring are operating-design proposals, not services hidden behind the diagram.
